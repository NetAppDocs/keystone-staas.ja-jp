= Keystoneの運用モデル
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
NetApp Keystoneは、Keystone Storage-as-a-Service（STaaS）およびKeystone XaaSサブスクリプションサービスを通じて提供されます。Keystone STaaSはパートナー運営およびお客様運営の運用モデルをサポートしますが、Keystone XaaSはNetAppパートナーからのみ提供されます。ご利用のサービスと運用モデルによって、ストレージ環境の管理、日常業務の処理、およびサポートの提供を誰が行うかが決まります。



[[keystone-staas-operational-models]]
== Keystone STaaSの運用モデル

Keystone STaaSの運用モデルは、サービスライフサイクル全体におけるNetApp、パートナー、およびお客様の責任を定義します。以下のセクションでは、パートナー運用モデルとお客様運用モデルについて説明します。



[[partner-operated-model]]
=== パートナー運営モデル

パートナーは、サービスプロバイダまたはリセラーとしてKeystone STaaSを提供できます。責任範囲は、パートナーとの契約内容によって異なります。サービスプロバイダまたはパートナーにお問い合わせのうえ、どのタスクが代行されるかをご確認ください。

*サービスプロバイダー*：サービスプロバイダーは、エンドユーザー向けにサービスを運営します。NetAppとの契約当事者として、サービスプロバイダーはマルチテナント環境を管理します。各テナントはサービスプロバイダーの顧客であり、サービスプロバイダーが直接請求する個別のサブスクリプションを持っています。サービスプロバイダーの管理者は、テナントに関するすべての管理業務を行う責任を負います。*再販業者*：再販業者として、パートナーはNetAppとお客様の間の橋渡し役を務めます。パートナーはKeystoneサービスをエンドユーザーに販売し、請求を管理します。パートナーが請求処理を担当する一方で、NetAppはお客様に直接サポートを提供します。Keystoneサポートはお客様とやり取りを行い、テナントに関するすべての管理業務を処理します。



[[customer-operated-model]]
=== 顧客運営モデル

顧客運用モデルでは、お客様のストレージ要件と選択したパフォーマンスサービスレベルに基づいてKeystone STaaSをサブスクライブします。NetAppはアーキテクチャと製品を定義し、お客様の施設にストレージを導入します。

ストレージチームとITチームがインフラストラクチャを管理します。貴組織の管理者が、貴組織環境内のユーザーに対して管理業務を実行します。契約内容によっては、NetAppまたはサービスプロバイダーにサービスリクエストを送信できます。

[[keystone-xaas-partner-delivery-and-support]]
== Keystone XaaSパートナーの提供とサポート

Keystone XaaSは、NetApp Keystoneの独立したサブスクリプションサービスであり、NetAppパートナーが独占的に提供します。パートナーは、エンドユーザーにサービスを提供し、サポートや日常業務を管理します。

Keystone XaaSをご利用の場合は、サービスおよびサポートについて直接のパートナーにお問い合わせください。上記のKeystone STaaS運用モデルおよびお客様運用の責任表には、Keystone XaaSの責任範囲は記載されていません。
