NetApp Keystoneは、初期投資やリースよりも運用コストとしての消費を好む企業向けの従量課金制サブスクリプションサービスであるKeystone Storage-as-a-Service（STaaS）を提供するプラットフォームです。



[[keystone-staas-offering-and-services]]
== Keystone STaaSの提供内容とサービス

Keystone STaaSは、ストレージインフラストラクチャの調達、導入、管理において、パブリッククラウドに似たモデルを提供します。Keystone STaaSをサブスクライブすると、お客様の要件を満たすデータストレージの種類とパフォーマンスサービスレベルを選択できます。

Keystone STaaSは、ストレージ機能の提供方法と利用方法を定義するサービスです。サービスとは、その製品・サービスで利用できる機能のことです。標準サービスは基本サブスクリプションに含まれており、追加機能が必要な場合はアドオンサービスを購入できます。例えば、高度なデータ保護（ADP）は、サポートされている構成に対して同期的なサイト間ミラーリングを提供するアドオンサービスです。

この区別は、どの機能がサブスクリプションに含まれ、どの機能に追加購入が必要かを理解するのに役立ちます。標準サービスおよび追加サービスについては、link:../concepts/supported-storage-services.html["Keystone STaaSサービス"]を参照してください。



[[storage-flexibility-and-operational-models]]
== ストレージの柔軟性と運用モデル

Keystone STaaSは、複数のデータストレージタイプとパフォーマンスサービスレベルをサポートしています。オンプレミスストレージから開始し、要件の変化に応じてクラウドサービスを追加できます。容量の調整およびクラウドの再割り当ては、サブスクリプション条件に従います。

Keystone STaaSは、パートナー運営モデルまたはお客様運営モデルのいずれかで運用できます。詳細については、link:../concepts/operational-models.html["Keystoneの運用モデル"]を参照してください。



[[key-benefits-of-keystone-staas]]
== Keystone STaaSの主な利点

* *コスト効率*：契約済みの容量については予測可能なコストで済み、契約容量を超えた消費量については使用量に応じた料金が発生します。
* *資本効率*：多額の初期投資なしにエンタープライズストレージにアクセスできます。
* *拡張性*：ビジネスの成長に合わせてストレージ容量を増やすことができます。
* *柔軟性*：ストレージプランを調整し、必要に応じてワークロードをクラウドに移行できます。
* *クラウド統合*：単一のサブスクリプションでオンプレミスとクラウドのサービスを利用できます。
* *セキュリティ*：高度なセキュリティ対策と復旧機能でデータを保護します。
