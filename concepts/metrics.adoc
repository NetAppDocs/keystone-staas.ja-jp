= Keystone STaaS ストレージのメトリクスと定義
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Keystone STaaS は、ストレージサブスクリプションの測定とレポート作成に特定の用語を使用します。これらの用語を理解することで、ダッシュボードのデータやサブスクリプションレポートを解釈しやすくなります。

[cols="1,3"]
|===
| 期間 | 定義 


| 容量（GiB、TiB、PiB） | データストレージ容量は1024のべき乗で測定されます：1 GiB = 1024^3^ バイト、1 TiB = 1024^4^ バイト、1 PiB = 1024^5^ バイト。 


| IOPS | IOPS（1秒あたりのI/O操作数）とは、アプリケーションが1秒あたりに要求するプロトコル操作の数です。IOPSは、Keystoneダッシュボードのオペレーションカウンターチャートに表示されます。 


| 可用性 | 可用性とは、1か月間に行われたI/Oリクエストの総数のうち、サービスが正常に応答したI/Oリクエストの割合です。これは、1か月間のサービス境界点における計測値であり、計画的なサービス停止時間や、お客様が提供する設備、ネットワーク、その他のサービスの利用不能時間は含まれません。 


| 耐久性 | 耐久性とは、顧客による削除や破損を除き、データの忠実度を損なうことなくアクセスできるデータの割合を指します。 


| レイテンシ | レイテンシーとは、クライアントから受信したI/O要求を処理するのにかかる時間であり、サービス境界点（ストレージコントローラのI/Oポート）で測定されます。 
|===
